## 一、R1 配置

```
sysname R1
#
interface GigabitEthernet0/0/1
 ip address 172.17.11.1 255.255.255.0
#
interface GigabitEthernet0/0/2
 ip address 172.17.12.1 255.255.255.0
#
interface GigabitEthernet0/0/3
 ip address 203.0.114.1 255.255.255.0
#
ospf 1 router-id 1.1.1.1
 area 0.0.0.0
  network 172.17.11.0 0.0.0.255
  network 172.17.12.0 0.0.0.255
#
acl number 2000
 rule permit source 172.17.0.0 0.0.255.255
#
interface GigabitEthernet0/0/3
 nat outbound 2000
#
ip route-static 0.0.0.0 0.0.0.0 203.0.114.2
#
return
```

**讲解：**
- 三个接口地址严格按表配置。
- OSPF 只宣告内网两个网段（172.17.11.0/24、172.17.12.0/24），公网口 203.0.114.0/24 不进 OSPF。
- ACL 2000 放行整个 172.17.0.0/16 私网段；`nat outbound 2000` 在 G0/0/3 出方向做 Easy-IP（直接借用该口公网地址做 PAT）。
- 最后一条默认路由指向 PC5 所在的下一跳（图上若为 203.0.114.2，按实际改），让 R1 自己也能去外网。

## 二、S1 配置

```
sysname S1
#
vlan batch 10 20 110
#
stp region-configuration
 region-name huawei
 revision-level 1
 instance 1 vlan 10
 instance 2 vlan 20
 active region-configuration
#
stp instance 1 priority 4096
stp instance 2 priority 8192
#
interface Vlanif10
 ip address 172.17.10.254 255.255.255.0
#
interface Vlanif110
 ip address 172.17.11.2 255.255.255.0
#
interface GigabitEthernet0/0/1
 port link-type access
 port default vlan 110
#
interface GigabitEthernet0/0/2
 port link-type trunk
 port trunk allow-pass vlan 10 20
#
interface GigabitEthernet0/0/3
 port link-type trunk
 port trunk allow-pass vlan 10 20
#
interface GigabitEthernet0/0/4
 port link-type trunk
 port trunk allow-pass vlan 10 20
#
ospf 1 router-id 11.11.11.11
 area 0.0.0.0
  network 172.17.10.0 0.0.0.255
  network 172.17.11.0 0.0.0.255
#
ip route-static 0.0.0.0 0.0.0.0 172.17.11.1
#
return
```

**讲解：**
- MSTP 域参数四台交换机必须完全一致（region-name、revision、实例—VLAN 映射），否则不在同一个 MST 域。
- 实例 1（VLAN10）优先级 4096 → S1 成为 VLAN10 的根桥，VLAN10 流量走 S1；实例 2（VLAN20）优先级 8192 → S2 是 VLAN20 的根桥。
- 与 R1 相连的 G0/0/1 划到 VLAN110（access），三层网关放在 Vlanif110。
- 与 S2/S3/S4 相连的口全部 trunk，只放行 10、20（110 只在 S1 本地到 R1 用，不需要 trunk 传递）。
- OSPF 宣告 VLAN10 和 VLAN110 两个三层段；默认路由指向 R1 的 172.17.11.1。

## 三、S2 配置

```
sysname S2
#
vlan batch 10 20 120
#
stp region-configuration
 region-name huawei
 revision-level 1
 instance 1 vlan 10
 instance 2 vlan 20
 active region-configuration
#
stp instance 1 priority 8192
stp instance 2 priority 4096
#
interface Vlanif20
 ip address 172.17.20.254 255.255.255.0
#
interface Vlanif120
 ip address 172.17.12.2 255.255.255.0
#
interface GigabitEthernet0/0/1
 port link-type access
 port default vlan 120
#
interface GigabitEthernet0/0/2
 port link-type trunk
 port trunk allow-pass vlan 10 20
#
interface GigabitEthernet0/0/3
 port link-type trunk
 port trunk allow-pass vlan 10 20
#
interface GigabitEthernet0/0/4
 port link-type trunk
 port trunk allow-pass vlan 10 20
#
ospf 1 router-id 22.22.22.22
 area 0.0.0.0
  network 172.17.20.0 0.0.0.255
  network 172.17.12.0 0.0.0.255
#
ip route-static 0.0.0.0 0.0.0.0 172.17.12.1
#
return
```

**讲解：**
- 与 S1 镜像：实例 1 优先级 8192（VLAN10 备份根），实例 2 优先级 4096（VLAN20 根桥），实现 VLAN20 流量走 S2。
- 注意 S2 上**没有** Vlanif10，VLAN10 的网关在 S1；VLAN20 的网关在 S2。这样不同 VLAN 的用户流量天然按 MSTP 设计走不同核心交换机，再由 R1 做跨 VLAN 转发（通过 OSPF 学到对方网段）。
- 默认路由指向 R1 的 172.17.12.1。

## 四、S3 配置

```
sysname S3
#
vlan batch 10 20
#
stp region-configuration
 region-name huawei
 revision-level 1
 instance 1 vlan 10
 instance 2 vlan 20
 active region-configuration
#
interface Ethernet0/0/1
 port link-type access
 port default vlan 10
#
interface Ethernet0/0/11
 port link-type access
 port default vlan 20
#
interface Ethernet0/0/2
 port link-type trunk
 port trunk allow-pass vlan 10 20
#
interface Ethernet0/0/3
 port link-type trunk
 port trunk allow-pass vlan 10 20
#
return
```

**讲解：**
- S3 是二层接入交换机，**不需要任何 IP 配置和路由**（没有管理 IP 也能跑）。
- E0/0/1、E0/0/11 按题目表分别划入 VLAN10、VLAN20（access 接 PC）。
- 上联 S1、S2 的两个口做 trunk，放行 VLAN10、20。
- MSTP 参数与 S1/S2 完全一致，自动计算：VLAN10 流量从 S1 方向上来，VLAN20 流量从 S2 方向上来，另一条上联被阻塞。
